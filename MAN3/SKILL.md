# 目的
プロジェクトの目的を達成するために必要な活動を論理的な段階（フェーズ）に分割し、スケジュール、予算、およびエージェントの役割を適切に割り当てることで、効率的かつ制御された開発を実現すること。

# インプット
- 顧客要求事項: `c:\AntiGravity\Gantt\00_req.md`
- プロジェクトのリスク状況: `c:\AntiGravity\Gantt\SWE_report\MAN5\05_RiskManagementReport.md`
- 過去の進捗実績: `c:\AntiGravity\Gantt\SWE_report/` 配下の既存成果物
- 報告書テンプレート: `c:\AntiGravity\Gantt\SWE_agent\MAN3\TEMPLATE.md`

# 手順
1. **フェーズ分割**: プロジェクトのライフサイクルを A-SPICE の各プロセス（SWE1-6, SUP, PIM等）に合わせ、複数の実行段階に分割します。
2. **スケジューリング**: 各段階の開始・終了予定日、マイルストーン、および依存関係を定義します。
3. **資源の割り当て**: 各担当プロセスに対する具体名（エージェント名、スキル名）を明記し、責任範囲を定義します。
4. **目標達成基準の策定**: 各フェーズおよびプロジェクト全体の完了を判定するための KPI（キー・パフォーマンス・インジケーター）を設定します。
5. **計画書の作成・更新**: テンプレートに従い、`c:\AntiGravity\Gantt\SWE_report\MAN3\00_ProjectPlan.md` を出力します。

# アウトプット
- プロジェクト計画書: `c:\AntiGravity\Gantt\SWE_report\MAN3\00_ProjectPlan.md`

# 制約事項
- 出力はすべて日本語で行うこと。
- 計画は静的なものではなく、進捗やリスクの変化に応じて随時更新（ローリングウェーブ計画）すること。
- **必ず指定された TEMPLATE.md の構造を維持し、A-SPICE MAN.3 のベストプラクティスに従うこと。**
