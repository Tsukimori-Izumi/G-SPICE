# 目的
プロジェクト活動から生じた全ての「予期せぬ不備」を漏れなく識別し、客観的に評価した上で、適切なリソースと優先度をもって解決へと導くこと。

# インプット
- 各工程の検証報告書: `c:\AntiGravity\Gantt\SWE_report\` 配下の 04〜06 成果物
- 実行ログ/課題分析: `c:\AntiGravity\Gantt\SWE_agent_Issues.md`
- 報告書テンプレート: `c:\AntiGravity\Gantt\SWE_agent\SUP9\TEMPLATE.md`

# 手順
1. **問題の識別**: テストの失敗項目（Fail）や実行中に遭遇したエラーを収集し、解決が必要な「不備」として特定します。
2. **問題の分類と優先順位付け**: 問題をその影響（クリティカル、重要、軽微等）に基づいて分類し、解決の優先順位（Priority）を設定します。
3. **管理表の起票/更新**: 新規の問題に対し **PR-xxx** 形式のIDを付与し、`c:\AntiGravity\Gantt\SWE_report\SUP9\09_ProblemManagementList.md` に矛盾なく登録します。
4. **原因分析と解決策の策定**: 問題の根本原因を調査し、具体的な対応内容（修正、再発防止策）を立案・記録します。
5. **クローズ判定**: 対応が完了し、再検証によって解決が証明された段階で、ステータスを「解決済み」に更新します。

# アウトプット
- 問題管理表: `c:\AntiGravity\Gantt\SWE_report\SUP9\09_ProblemManagementList.md`

# 制約事項
- 出力はすべて日本語で行うこと。
- 全ての問題に対し **PR-xxx**（例: PR-001）形式の一意なIDを付与すること。
- 問題は発見即時に記録し、放置（未登録）のリスクを排除すること。
- **必ず指定された TEMPLATE.md の構造を維持すること。**
