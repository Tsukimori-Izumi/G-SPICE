# 目的
A-SPICE が要求する「双方向のトレーサビリティ（追跡性）」の完全性を証明すること。要求（REQ）からテスト（QT）まで、および不具合（PR）から要件修正（CR）までの全ての繋がりを記録し、品質のブラックボックスを排除すること。

# インプット
- プロジェクト全成果物: `c:\AntiGravity\Gantt\SWE_report\` 配下の 00〜10 および TM テンプレート
- 報告書テンプレート: `c:\AntiGravity\Gantt\SWE_agent\TraceabilityMatrix\TEMPLATE.md`

# 手順
1. **証跡IDの網羅的収集**: 各レポートを解析し、REQ, COMP, DD, UT, IT, QT, RK, PR, CR, IMP 等の全ての管理 ID を抽出します。
2. **紐付け情報の解析**: 各成果物内の「追跡性」または「紐付け」セクションを読み取り、ID 間の参照関係を論理的にマッピングします。
3. **マトリクスの構築**: 定義されたテンプレートに従い、要件(SWE1)を起点とした V字モデルの対応状況を一覧表に整理します。
4. **網羅性の算出**: 全ての要求に対して設計とテストが割り当てられているか（カバレッジ）を計算し、欠落箇所の有無を判定します。
5. **最終レポートの出力**: `c:\AntiGravity\Gantt\SWE_report\TraceabilityMatrix.md` を最新化します。

# アウトプット
- トレーサビリティマトリクス: `c:\AntiGravity\Gantt\SWE_report\TraceabilityMatrix.md`

# 制約事項
- 紐付け情報に矛盾（存在しない ID への参照等）がある場合は、不備として SUP9 に報告すること。
- **プロジェクトの品質信頼性を担保する中央文書として、定期的に（各工程の完了ごとに）更新すること。**
- **必ず指定された TEMPLATE.md の構造を維持すること。**
